## **Notes**

This image can be used to spawn containers of ubuntu with an XFCE desktop environment.\
Customize **Dockerfile** for the needed ubuntu version. Update **run_me.sh** with the same.\
Customize **run_me.sh** to suite your machine's parameters (eg: Graphics card support).

For running an app with graphics card:
/opt/VirtualGL/bin/vglrun <app name, eg: firefox>
